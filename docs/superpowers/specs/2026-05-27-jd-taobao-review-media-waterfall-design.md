# 京东与淘宝评价实拍墙油猴脚本设计

## 目标

开发一个油猴脚本，为京东和淘宝商品评价中的用户图片与视频提供更高效的连续浏览方式。用户从商品评价区域一键打开较大的“实拍墙”弹窗，在不离开当前商品页的情况下，以瀑布流浏览真实用户上传的媒体内容，并能放大图片或播放视频查看评价上下文。

## 范围

首版覆盖：

- 京东商品详情页评价区域。
- 淘宝商品详情页评价弹窗或评价区域。
- 评价中的图片和视频封面。
- 平台原有图/视频、排序、商品或款式筛选条件。
- 自动加载更多媒体内容。

首版不提供：

- 评价文字全文检索。
- 下载、批量收藏或导出媒体。
- 跨商品聚合。
- 脚本自行定义的平台筛选规则。

## 入口与平台融合

### 京东

在商品页评价区域上方的页签栏中，与“大家评”“店铺”“商品详情”“售后保障”“推荐”等入口同一行增加“实拍墙”入口。入口视觉应接近当前页签风格，但通过文案让用户能区分脚本功能与原页面功能。

点击入口后打开脚本的大尺寸弹窗。脚本应以真实页面分析为依据，使用或映射京东原评价界面已有的“图/视频”“最新”“当前商品”等筛选状态。

### 淘宝

在真实页面中找到原评价查看入口或原有图集操作区，在不遮挡“图/视频”“图集”“默认排序”“款式筛选”等现有控件的前提下增加“实拍墙”入口。具体节点和插入顺序需在实页 DOM 取证后确定。

点击入口后打开同一交互模型的大尺寸弹窗。脚本应使用或映射淘宝已有的“图/视频”、排序和款式筛选状态。

## 核心交互

### 图片墙弹窗

- 用户点击“实拍墙”后，在当前商品页上方打开较大的遮罩弹窗。
- 弹窗内部包含标题、关闭按钮、平台对应筛选区域、媒体瀑布流区域和加载状态区域。
- 卡片默认仅展示图片或视频封面，不展示评价文字，以最大化浏览效率。
- 视频卡片具有清晰的播放标识，不默认自动播放。
- 首批媒体展示完成后，滚动接近底部自动加载下一批符合当前筛选条件的媒体。
- 没有更多内容、加载失败或当前筛选下没有媒体时，应给出明确状态提示。

### 图片与视频预览

- 点击图片卡片，在图片墙弹窗内部进入放大预览层。
- 点击视频卡片，在相同预览层中播放视频。
- 预览层显示对应评价的文字、规格或款式、日期等能从当前平台可靠取得的上下文信息。
- 图片或视频本体上的点击不应关闭预览。
- 点击预览内容外的空白区域，关闭预览层并回到图片墙。

### 关闭逻辑

- 图片墙状态下，点击整个图片墙弹窗外部的遮罩区域，退出实拍墙并回到商品页。
- 点击弹窗关闭按钮，在任意非浏览器原生播放器阻止的状态下退出整个实拍墙。
- 预览层打开时，首次点击预览层外区域仅退回图片墙，不同时关闭实拍墙。

## 筛选与数据行为

脚本不重新定义筛选语义。它应优先复用平台页面已经提供的筛选能力，并将当前筛选结果转换为媒体瀑布流：

- 京东保留图/视频筛选，以及“最新”“当前商品”等原页面可用选项。
- 淘宝保留图/视频、原有排序和款式筛选等原页面可用选项。
- 用户更改筛选后，当前瀑布流清空并从新条件的首批结果重新加载。
- 连续加载只追加当前筛选条件下的新内容；需要用评价标识或媒体地址去重，避免重复卡片。

具体使用 DOM 复用、模拟原生控件还是调用页面已发出的评价请求，将以 Kimi WebBridge 在用户当前 Chrome 登录态下采集到的 DOM 和请求行为为准。不能仅凭类名猜测选择器或请求参数。

## 结构建议

脚本采用单个发布文件，内部按职责划分清晰模块：

- `siteAdapter`：识别当前站点、定位入口、读取平台筛选状态、触发或读取媒体数据。
- `mediaStore`：保存媒体条目、分页状态、去重集合、加载中和结束状态。
- `wallModal`：渲染大尺寸弹窗、瀑布流、状态提示、关闭行为。
- `previewLayer`：图片放大、视频播放以及评价上下文呈现。
- `routeLifecycle`：处理商品页动态渲染与单页导航，确保入口只插入一次并在页面变化后重新绑定。

京东和淘宝应共享弹窗与预览层，只把站点差异隔离在适配器中，避免两份重复 UI 逻辑。

## 失败处理与约束

- 找不到目标评价区域时，不向页面插入错位入口；仅在调试开关开启时记录诊断信息。
- 平台请求失败、登录校验或风控阻止加载时，弹窗显示可恢复的失败提示，不无限重试。
- 图片失效时显示占位提示；视频无法直接播放时保留封面并提示无法播放。
- 站点改版导致适配器失效时，一个站点的失败不应影响另一站点的初始化。
- 元数据权限保持最小化；只有在真实请求验证表明必要时才增加跨域或 GM 请求权限。

## 实页取证与验证

实现前必须通过 Kimi WebBridge 连接用户实际打开的京东与淘宝页面，分别确认：

- 页面标题、URL 形态和登录态下可见的评价入口。
- 可稳定定位的入口容器、原生筛选控件、滚动容器与媒体节点。
- 图/视频筛选以及排序或款式选项改变时产生的 DOM 变化和相关网络请求。
- 媒体条目的图片原图、缩略图、视频地址或视频封面、评价上下文字段。

完成脚本后需在两个站点各验证：

- “实拍墙”入口只出现一次，位置与设计相符。
- 初次打开为图/视频媒体视图，瀑布流可以继续加载。
- 平台原有筛选条件改变后，图片墙内容按照该条件更新。
- 图片预览、视频预览、分层点击回退和关闭按钮行为准确。
- 页面路由变化或评价弹窗重开后，脚本不重复注入控件且无新增控制台错误。
