# 京东与淘宝评价图片墙增强设计

## 目标

在已发布的 `v0.3.0` 图片墙基础上，提高大量评价媒体连续浏览时的效率和反馈质量。保留现有京东/淘宝原生筛选复用、纵向图片墙、预览左右切换和关闭时联动退出原评价窗口的行为。

## 新增范围

本次实现以下功能：

1. 预览层显示当前媒体位置与总数，例如 `12 / 184`。
2. 完善键盘操作：卡片可聚焦，`Enter` 或 `Space` 打开预览；预览中 `ArrowLeft` / `ArrowRight` 切换；`Escape` 从预览回到图片墙，图片墙状态下再次按 `Escape` 退出。
3. 退出预览时，将图片墙滚动到当前媒体卡片并短暂高亮，保持浏览上下文。
4. 展示加载状态、当前已加载数量、没有更多内容和可重试的加载失败提示。
5. 提供 `小 / 中 / 大` 三档缩略图大小，分别对应快速扫图、默认浏览和细节浏览。
6. 提供 `全部 / 图片 / 视频` 本地媒体类型筛选，不改变平台原生评价筛选状态。
7. 预览右侧的评价信息可折叠和重新展开；折叠时媒体可使用更宽空间。
8. 预览层提供 `打开原图` 与 `下载原图` 操作，仅针对当前查看的单个媒体。
9. 关闭图片墙后在同一商品页再次打开，恢复本次页面会话内的已加载媒体、墙内滚动位置、缩略图大小、媒体类型筛选和最后查看位置。

## 不做范围

- 不在刷新、关闭标签页或进入其他商品后恢复浏览位置。
- 不提供批量下载、收藏、导出或跨商品聚合。
- 不主动重放需要签名的京东或淘宝评价接口请求。
- 不在本次加入虚拟列表；若真实页面媒体数量导致明显卡顿，再单独设计性能阶段。

## 交互设计

### 图片墙工具栏

弹窗标题区域继续显示“图片墙”，增加以下控制：

- 类型筛选：`全部`、`图片`、`视频`，切换仅影响墙内已收集内容，媒体继续按原生结果追加。
- 尺寸选择：`小`、`中`、`大`，默认 `中`；小尺寸提供更多列，大尺寸提供更少列。
- 状态文字：显示已加载的媒体数量；触底请求原生列表继续加载期间显示“正在加载更多”。

### 卡片与键盘

- 每个媒体卡片可用键盘聚焦；聚焦后按 `Enter` 或 `Space` 打开预览。
- 预览退出后，将预览停留的媒体卡片滚动至可视区域中央并加短时高亮。
- 筛选掉当前媒体时，不强制跳转到不可见卡片；墙仍保留最后滚动位置。

### 预览层

- 顶部或媒体周边显示当前位置，位置基于当前墙内类型筛选后的可见媒体集合。
- 左右按钮和 `ArrowLeft` / `ArrowRight` 在可见集合内切换。
- 评价信息区域提供折叠按钮；折叠仅影响本次打开图片墙的当前显示状态。
- `打开原图` 在新标签页打开当前媒体地址；`下载原图` 以链接下载当前图片或视频文件，由浏览器和站点跨域策略决定最终保存方式。

### 关闭与会话恢复

- `Escape` 与遮罩点击的分层关闭规则保持一致：先关闭预览，再关闭图片墙。
- 关闭图片墙仍同时关闭平台原评价窗口。
- 会话状态仅存于当前脚本实例的内存中，以站点当前商品页面为范围；关闭图片墙后重开恢复，页面刷新后自然清空。

## 数据与状态结构

在现有 `mediaStore`、`wallModal` 与 `previewLayer` 上扩展一个页面会话状态对象：

- `items`：已从当前平台原生评价获得并去重的媒体。
- `mediaFilter`：`all`、`image` 或 `video`。
- `cardSize`：`small`、`medium` 或 `large`。
- `scrollTop`：上次关闭或预览操作后图片墙的滚动位置。
- `previewKey`：最后预览媒体的唯一地址，用于重开及返回定位。
- `contextCollapsed`：评价信息折叠状态。
- `loadingState`：`idle`、`loading`、`exhausted` 或 `error`，并记录当前已加载条数。

适配器仍只负责打开、关闭、滚动原生评价区域及抽取真实媒体。墙内类型筛选、尺寸、定位和会话状态由共享 UI 管理，不向平台控件回写。

## 加载反馈

- 初次等待原生评价窗口时显示等待状态。
- 图片墙接近底部时，单次触发原生滚动加载；加载完成前不重复触发。
- 若一次加载未产生新媒体，再允许用户继续滚动重试；连续无新增达到合理次数后显示“没有更多内容”。
- 原生评价区域不可访问或加载过程抛出异常时显示错误状态及“重试”按钮，按钮再次执行同步和加载流程。

## 验证要求

自动化测试覆盖：

- 类型筛选、卡片尺寸和会话恢复状态。
- 预览索引采用当前可见媒体集合，并显示数量。
- 键盘动作、返回定位标记、加载锁和加载结束/重试状态。
- 单图打开/下载入口以及评价信息折叠状态。

真实页面验证覆盖：

- 淘宝/天猫图集数据在三档尺寸及本地类型筛选下无重叠，预览计数、定位、折叠、打开原图和下载入口可操作。
- 京东懒加载滚动期间状态反馈清晰，重复触底不会同时触发多轮加载，新增图片持续追加。
- 两个平台关闭并再次打开图片墙均恢复当前页会话位置；关闭仍退出原生评价窗口。
