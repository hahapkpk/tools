# Favicon Grabber 剪贴板读取与标题命名设计

## 目标

扩展 `favicon-grabber.html`：用户打开工具后，可以通过按钮读取剪贴板中的网站网址，沿用现有流程获取图标候选，并在下载图标时自动使用简洁、准确的网站名称生成文件名。

## 使用流程

1. 页面保留现有的网址输入框和粘贴后自动获取图标功能。
2. 新增醒目的“读取剪贴板网址并获取图标”按钮。用户点击后，页面读取剪贴板网址、填入输入框并开始获取图标。
3. 处理有效网址后，在图标卡片区域上方显示“保存名称”输入框。
4. 工具自动尝试读取网页标题，并将其整理为简洁、适合文件名的网站名称。
5. 用户可以在下载前手动修改生成的保存名称。
6. 每次下载都以当前保存名称作为文件名前缀，例如 `GitHub-Favicon.ico`。

## 浏览器限制与回退处理

浏览器通常限制网页在刚打开且未经用户操作时直接读取剪贴板，因此读取动作由用户点击按钮触发。如果浏览器不支持剪贴板读取、权限被拒绝，或剪贴板内容不是网址，页面给出明确提示，同时保留原有的手动输入和粘贴流程。

由于该工具是静态网页，直接跨域读取任意网站文档可能失败。标题解析不能阻塞图标获取流程：

- 尝试通过浏览器可访问的标题读取通道自动获得网页标题。
- 无法获得可用标题时，根据目标域名生成保存名称。
- 保存名称始终可编辑，方便用户修正不理想的自动结果。

标题读取失败时，图标候选仍正常显示和下载。

## 名称整理规则

自动生成的保存名称需要简洁，并适合 Windows 文件名：

- 优先保留标题中可识别的网站或品牌名称，避免带入过长的页面描述。
- 移除文件名非法字符，例如 `\ / : * ? " < > |`。
- 移除装饰性符号，并合并重复空格。
- 如果标题中存在明显的分隔符和后置描述，保留清晰的网站名称部分。
- 最长限制为 40 个字符，并去除结尾的标点或空格。
- 整理后没有有效名称时，回退为域名主体。

## 下载文件名

下载时将当前保存名称与图标来源名称组合，图标来源名称同样进行文件名安全处理。现有的直接下载与无法直接下载时的保存提示逻辑保持兼容。

示例：

- `GitHub-Favicon.ico`
- `微信读书-Apple-Touch-Icon.png`
- `OpenAI-Logo.svg`

## 异常处理

- 剪贴板权限被拒绝或浏览器不支持：显示可操作的提示，用户仍可手动输入网址。
- 剪贴板未包含网址：显示剪贴板网址无效的提示，不清空已有可用结果。
- 标题读取失败或超时：使用域名生成的保存名称，不阻止图标卡片显示。
- 用户清空保存名称后点击下载：重新应用按域名生成的后备名称。

## 验证内容

- 点击剪贴板按钮后，模拟有效网址能够触发现有获取流程。
- 标题整理能够移除过长描述和非法文件名字符。
- 过长名称会按定义的长度限制缩短。
- 标题读取失败时能够生成可用的域名保存名称。
- 下载文件名会带上当前保存名称前缀。
- 现有输入网址与粘贴触发流程继续可用。
