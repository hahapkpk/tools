# Favicon Grabber 剪贴板读取与标题命名设计

## 目标

新增 `favicon-grabber-v2.html`：以现有 `favicon-grabber.html` 的页面设计和图标获取逻辑为基础，增加剪贴板网址读取、标题命名和按网站名称保存图标功能。原页面保持不变，便于用户分别测试旧版与 V2。

## 使用流程

1. V2 页面保留现有的网址输入框、界面风格、图标来源和粘贴后自动获取图标功能。
2. 新增醒目的“读取剪贴板网址并获取图标”按钮。用户点击后，页面读取剪贴板网址、填入输入框并开始获取图标。
3. 处理有效网址后，在图标卡片区域上方显示“保存名称”输入框。
4. 工具自动尝试读取网页标题，并将其整理为简洁、适合文件名的网站名称。
5. 用户可以在下载前手动修改生成的保存名称。
6. 保存名称输入框右侧提供“复制名称”按钮，点击后复制当前网站名称本身，例如 `小红书` 或 `GitHub`。
7. 保存名称下方始终显示最多 3 个名称候选标签，点击标签可切换当前保存名称。
8. 下载格式可选择“保留原格式”或“自动转 PNG”，默认保留原格式。
9. 每次下载都以当前保存名称作为文件名前缀，例如 `GitHub-Favicon.ico`。

## 浏览器限制与回退处理

浏览器通常限制网页在刚打开且未经用户操作时直接读取剪贴板，因此读取动作由用户点击按钮触发。如果浏览器不支持剪贴板读取、权限被拒绝，或剪贴板内容不是网址，页面给出明确提示，同时保留原有的手动输入和粘贴流程。

由于该工具是静态网页，直接跨域读取任意网站文档会受到浏览器限制。V2 通过公开文本读取服务请求目标网站网址并提取标题；该请求只用于读取标题。标题解析不能阻塞图标获取流程：

- 尝试通过浏览器可访问的标题读取通道自动获得网页标题。
- 无法获得可用标题时，根据目标域名生成保存名称。
- 保存名称始终可编辑，方便用户修正不理想的自动结果。

标题读取失败时，图标候选仍正常显示和下载；原版页面不接入该请求。

## 名称整理规则

自动生成的保存名称需要简洁，并适合 Windows 文件名：

- 优先保留标题中可识别的网站或品牌名称，避免带入过长的页面描述。
- 标题中同时存在可用中文名和英文名时，优先采用简短中文站名，例如 `RED | 小红书 - 你的生活指南` 输出 `小红书`。
- 移除文件名非法字符，例如 `\ / : * ? " < > |`。
- 移除装饰性符号，并合并重复空格。
- 如果标题中存在明显的分隔符和后置描述，保留清晰的网站名称部分。
- 最长限制为 40 个字符，并去除结尾的标点或空格。
- 整理后没有有效名称时，回退为域名主体。

## 下载文件名

下载时将当前保存名称与图标来源名称组合，图标来源名称同样进行文件名安全处理。现有的直接下载与无法直接下载时的保存提示逻辑保持兼容。

示例：

- `GitHub-Favicon.ico`
- `微信读书-Apple-Touch-Icon.png`
- `OpenAI-Logo.svg`

每张图标卡片另提供“复制文件名”按钮，复制该卡片按当前保存名称和当前下载格式生成的完整文件名。选择“自动转 PNG”时，文件名扩展名同步改为 `.png`。

## 图标推荐与信息展示

- 所有成功加载的图标均保留展示，不因重复而隐藏。
- 推荐排序格式优先级为：`PNG > ICO > SVG > JPEG / WEBP / 其他`。
- 同格式下优先实际像素面积更大的图片；尺寸相同再优先网站直链来源。
- 当前排序第一的图标显示“推荐”标记。
- 位图显示读取到的真实宽高，例如 `实际 256×256`；SVG 显示 `矢量 SVG`。
- 对浏览器能够读取内容的数据生成指纹，内容一致的卡片增加“重复”标记；跨域限制下无法可靠读取内容时不推测重复。

## 名称候选

- 自动提取最多 3 个去重候选：中文短名称、英文品牌名称、域名后备名称。
- 默认选用中文短名称；没有中文名时选择英文名；都不存在时使用域名名称。
- 候选标签始终显示，包含一个候选时也显示一个。
- 用户点击候选标签后，覆盖“保存名称”输入框；后续复制与下载都采用新名称。

## 下载格式

- `保留原格式` 为默认模式，SVG、ICO、PNG 等按各自格式保存。
- `自动转 PNG` 模式下，对浏览器可加载并绘制到画布的图标生成 PNG 下载。
- 如果某张图标因跨域限制或格式解析限制不能转换，提示“无法转换，已按原格式保存”，并下载原始格式。

## 异常处理

- 剪贴板权限被拒绝或浏览器不支持：显示可操作的提示，用户仍可手动输入网址。
- 剪贴板未包含网址：显示剪贴板网址无效的提示，不清空已有可用结果。
- 标题读取失败或超时：使用域名生成的保存名称，不阻止图标卡片显示。
- 用户清空保存名称后点击下载：重新应用按域名生成的后备名称。
- 复制名称失败：提示无法复制，不改变当前名称及下载行为。
- 图标转 PNG 失败：显示回退提示，继续按原格式下载。

- 原始 `favicon-grabber.html` 在功能提交中没有变更。
- 点击剪贴板按钮后，模拟有效网址能够触发现有获取流程。
- 标题整理能够移除过长描述和非法文件名字符。
- 标题同时包含中文名和英文名时优先得到中文名。
- 点击“复制名称”会复制当前网站名称，而不是完整图标文件名。
- 过长名称会按定义的长度限制缩短。
- 标题读取失败时能够生成可用的域名保存名称。
- 下载文件名会带上当前保存名称前缀。
- 推荐排序符合 `PNG > ICO > SVG > 其他`，并在同格式内按真实尺寸排序。
- 卡片显示真实尺寸，重复卡片保留并可标记重复。
- 卡片“复制文件名”根据当前保存名称和导出模式生成完整名称。
- 名称候选最多 3 个、去重并可点击切换。
- 自动转 PNG 成功时输出 `.png`，转换失败时回退原格式。
- 现有输入网址与粘贴触发流程继续可用。
